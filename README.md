# KiPiZK - Remove Background Gratis

Website untuk menghapus background gambar secara otomatis menggunakan AI. 100% gratis, tanpa iklan, dan processing dilakukan di browser (tidak ada upload ke server).

## Fitur

- ✅ Remove background otomatis dengan MediaPipe AI
- ✅ Upload gambar (drag & drop / click)
- ✅ Preview original vs hasil
- ✅ Download PNG transparent
- ✅ 100% client-side processing (privacy terjaga)
- ✅ Dark theme minimalis elegan
- ✅ Responsive mobile-friendly

## Teknologi

- HTML/CSS/JavaScript (Vanilla)
- @imgly/background-removal (RMBG AI Model)
- Universal object segmentation (bukan hanya manusia)
- Google Fonts (Inter)

## Deploy

Deploy ke Vercel:

```bash
vercel --prod
```
